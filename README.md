# Vizinapp-banco-de-dados
Banco de dados para o Vizinapp

Este repositório contém a infraestrutura de dados para o VizinApp, uma plataforma digital desenvolvida para facilitar a comunicação entre associações de moradores, cidadãos e órgãos públicos na resolução de problemas de infraestrutura.

 Estrutura do Projeto
- Implementação Física (DDL): Scripts SQL de criação das tabelas normalizadas (`AssociacaoMoradores`, `Usuario`, `Secretaria`, `StatusSolicitacao`, `Solicitacao`).
- Povoamento (DML): Scripts de inserção de registros para testes de carga e integridade.
- Consultas Analíticas: Queries estruturadas para análise de dados e extração de relatórios.
